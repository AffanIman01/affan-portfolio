Learning focus

Deepen understanding of phase/frequency detectors, charge pumps, loop filters, voltage-controlled oscillators (VCOs), dividers, and loop behaviour.

Layout perspective

Charge-pump matching, oscillator isolation, supply noise, and sensitive control-voltage routing.

Planned exercise

Build a block-level PLL model and study the trade-off between settling behaviour and jitter filtering.

DLL

Delay control & clock alignmentExplore learning path +

Learning focus

Study delay-locked loops, phase detection, controlled delay lines, lock range, and clock deskew.

Layout perspective

Consistent delay-cell placement, balanced clock routes, loading, and supply sensitivity.

Planned exercise

Model a delay chain and observe how feedback aligns its output clock with a reference.

Memory

SRAM, DRAM, ROM & HBMExplore learning path +

Learning focus

Strengthen memory fundamentals: 6T SRAM read/write operation and stability, DRAM charge storage and refresh, ROM organisation, and HBM architecture.

Layout perspective

Bitcell regularity, wordline/bitline loading, sense-amplifier matching, and array/periphery interfaces.

Planned exercise

Start with a 6T SRAM schematic and operating-state study, then explore a small array and its peripheral blocks.

RFIC

Low-noise amplifiers & mixersExplore learning path +

Learning focus

Develop understanding of LNAs, mixers, variable-gain amplifiers, impedance matching, noise, and linearity.

Layout perspective

Differential routing, shielding and return paths, substrate coupling, and passive-device placement.

Planned exercise

Study an LNA schematic and annotate its signal path, bias network, and layout-sensitive connections.

Layout Verification

PEX, post-layout behaviour & reliabilityExplore learning path +

Learning focus

Build on DRC/LVS experience towards parasitic extraction (PEX), schematic-versus-extracted comparison, and electromigration/IR-drop awareness.

Layout perspective

Relate routing and device placement to circuit behaviour, matching, and robust power connections.

Planned exercise

When extraction tools and a suitable PDK are available, compare a small analog block before and after extraction and document the differences.
